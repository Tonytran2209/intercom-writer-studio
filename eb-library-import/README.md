# EB Library import set

Upload the four Markdown files in this directory into **Settings → EB Knowledge & Rules → EB Library**. They map one-to-one to the V2 reference collections:

| File | EB Library collection | Used by |
| --- | --- | --- |
| `pillar-library.md` | EVP Pillars | Gate 1 mapping |
| `persona-library.md` | Persona Library | Gate 1 mapping |
| `article-library.md` | Article Library & repetition log | Gates 1–3 and final logging |
| `channel-rules.md` | Channel Rules | Adapt channel |

Do not upload `SKILL.md` into the library: it is the orchestration specification. Do not upload `how-it-works-for-freshers.md`: it is onboarding help, not a prompt reference.

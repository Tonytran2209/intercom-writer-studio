# Channel Rules

## Threads

**Confirmed from Chi's own Threads strategy documentation.**

- **Language:** Vietnamese.
- **Voice:** trendy, Gen Z-approachable, storytelling-lean. Write as a 24-year-old Vietnamese person working in employer branding would — not as a corporate account.
- **Hard limit:** 500 characters (~75–100 words). This is a platform constraint — count characters before finalizing, don't just estimate.
- **Positioning:** F.'s Threads approach is deliberately the minority pattern in the market — indirect recruitment via daily-life/culture content, not JD-posting (2.1) or tips-sharing (2.2), both of which underperform for recruitment purposes per Chi's documented observation. Never lead with job details, "mức lương hấp dẫn," or "việc nhàn" bait.
- **Targets:** primarily junior/entry-level and Gen Z–Millennial roles (animator, motion designer, content, account) — not senior/finance/legal/C-level.
- **Cross-platform funnel:** Threads → fab.careers apply page → interview. Any CTA should resolve toward this, not a separate destination.
- **Two variants required every run:**
  - **Variant A — Company account:** broader culture framing, still casual/Gen-Z voice, posted as F.Learning.
  - **Variant B — Employee-shareable:** same moment, told first-person as if a specific teammate is personally sharing it — more intimate, less official.
  - *(Default design, not yet finalized by Chi: Variant B zooms into one specific personal detail within the same instance rather than just rewording Variant A — this follows Chi's own documented observation that personal/employee shares outperform company-account shares. Adjust if her intent differs.)*
- **Virality check:** if the moment has real viral potential (surprising, funny, highly relatable), add a suggested sub-thread reply (posted shortly after the main thread, adding a detail or reaction) and 5 seeding comments — vary these across a question, an agreement, a tag-a-friend prompt, a light joke, and a personal relate, rather than 5 versions of the same reaction.

## Facebook

**Confirmed from Chi's brief + 2 real example posts.**

- **Audience:** ~1,000 warm followers — people who want to join the talent pool, plus current and past employees. This is not cold reach; some familiarity with F. can be assumed.
- **Language:** Vietnamese first, English translation directly after — both included every run.
- **Length:** ~200 words max per language version. No hard platform limit, but keep it tight regardless.
- **Formatting:** include emoji/icons (bullet-style emoji for lists, matching the example posts). Job titles in recruiting CTAs use bold unicode formatting (𝐁𝐨𝐥𝐝 𝐭𝐞𝐱𝐭 𝐬𝐭𝐲𝐥𝐞), matching the reference posts' native styling convention.
- **Two sub-forms** — pick based on the input, or ask Chi if genuinely unclear:
  - **Reflective (values-led):** thesis statement → 3 bolded small-moment bullets, each ending on a quoted emotional phrase ("...you're part of the story.") → closing line reframes the moments into a named value → soft CTA ("Check out more of our stories here: [fab.careers link]"). No job links, no hashtags.
  - **POV/narrative-led:** immersive scene-set (POV framing, or a timeline with timestamps, playful escalating tension) → 3 bolded lesson bullets tying the activity back to work values → closing line ties the activity to company identity → direct CTA with open job links + hashtags (#FLearningStudio #LifeAtF + 1–2 relevant, e.g. #POV #Hiring).
  - *(Default logic, not yet finalized by Chi: use POV/narrative-led when the input includes a specific event AND there are open roles to attach; use Reflective when the input is a general culture/atmosphere observation with no active hiring push.)*

## LinkedIn

**Draft — standard employer-branding logic, not yet confirmed against a real F. LinkedIn strategy doc (unlike Threads and Facebook above). Replace once Chi provides one.**

- **Language:** English.
- **Goal:** open exposure — broad visibility and credibility with passive candidates and industry peers, secondarily with clients/partners who also see the company page.
- **Funnel stage:** MOFU (reader is already evaluating, not just browsing).
- **Structure:** hook (a genuine insight or moment, not a gimmick) → short context/story → the principle or lesson it demonstrates → reflective close → soft-to-medium CTA (careers page link by default; a direct job link only if actively hiring for a directly relevant role).
- **Tone:** warm but professional — no meme format, no POV/timeline chaos borrowed from Threads/Facebook. The same underlying value (e.g. "hierarchy doesn't matter here") needs to land through a more measured story or reflection on this channel, not the same POV script reused.
- **Open flag:** LinkedIn is the platform most likely to double as credibility content for clients, not just candidates — confirm with Chi if the skill should account for that dual audience explicitly, or stay candidate-only.
